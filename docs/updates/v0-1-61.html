v0.1.61 — 70-Kill Offline Core Defense

Each Offline Story Core Defense now completes at 70 legitimate kills instead of 80, with the HUD and resumed progress using the same target.

Story

  • Every Offline Story Core placement now requires 70 legitimate kills.
  • The HUD displays progress out of 70; skipped spawns do not lower the target, and compatible saves restore against it.
  • Core rewards, the three-Core sequence, spawn pacing, and the separate shared/Online target are unchanged.
