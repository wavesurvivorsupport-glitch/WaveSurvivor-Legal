v0.2.36 - Active-District minimap framing

Chapter minimap focuses on the current entered District while retaining earlier discovery, static framing, heading-up rotation and shared marker projection.

Static active-District focus

  • CHANGED: Chapter minimap now frames the current entered District instead of fitting the entire revealed Chapter. Each District uses its own authored floor center and all-heading-safe scale, keeping later Districts readable.
  • PRESERVED: Previously discovered Districts and corridors remain revealed and render wherever they fall within the current crop. Discovery alone does not reframe the view; canonical District entry selects the next frame with the existing short smooth transition.
  • PRESERVED: The map stays static between District entries, rotates heading-up, and uses the existing shared player/enemy/Core/objective projection and marker sizes. Player-follow panning, the old coverage solver and Chapter Core zoom remain disabled. No gameplay, geometry, checkpoints, rewards or combat values changed.
